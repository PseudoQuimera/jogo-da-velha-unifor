Ferramenta: ChatGPT
Modelo: GPT-5
Fornecedor: OpenAI
Prompt 1 — Geração do README do Projeto

Prompt enviado:

README.md: Deve conter o título do projeto, seu nome completo, matrícula, instruções de execução e o link público gerado pelo GitHub Pages rodando a aplicação. Gere o README https://pseudoquimera.github.io/jogo-da-velha-unifor/. Utilize o index.html do link https://github.com/PseudoQuimera/jogo-da-velha-unifor/tree/main/src de referência.

Objetivo do prompt:

Gerar o arquivo README.md do projeto Jogo da Velha contendo as informações exigidas pela atividade, incluindo identificação do autor, descrição do sistema, funcionalidades, tecnologias utilizadas, instruções para execução local e o link da aplicação publicada no GitHub Pages.

Resposta obtida:

A IA produziu um arquivo README.md estruturado em Markdown contendo:

Título do projeto;
Nome do autor;
Campo para matrícula;
Descrição da aplicação;
Lista de funcionalidades principais;
Tecnologias utilizadas;
Instruções para execução local;
Estrutura básica do projeto;
Link público da aplicação hospedada no GitHub Pages.

Resultado obtido:

O README foi gerado de forma compatível com os requisitos da atividade, restando apenas o preenchimento manual da matrícula do aluno antes da entrega final.
