## Descrição

Projeto desenvolvido para a disciplina da Universidade de Fortaleza (UNIFOR), consistindo em uma aplicação web de **Jogo da Velha**. O sistema permite partidas entre dois jogadores ou contra o computador, além de oferecer diferentes formatos de disputa e controle de pontuação.

## Funcionalidades

* Partida entre dois jogadores;
* Modo de jogo contra o computador;
* Controle de rodadas;
* Sistema de pontuação;
* Identificação automática do vencedor;
* Reinício da partida a qualquer momento;
* Interface web responsiva e intuitiva.

## Tecnologias Utilizadas

* HTML5
* CSS3
* JavaScript

## Como Executar o Projeto

### Opção 1 – Acessar Online

A aplicação está disponível através do GitHub Pages:

👉 https://pseudoquimera.github.io/jogo-da-velha-unifor/

### Opção 2 – Executar Localmente

1. Clone este repositório:

```bash
git clone https://github.com/PseudoQuimera/jogo-da-velha-unifor.git
```

2. Acesse a pasta do projeto:

```bash
cd jogo-da-velha-unifor
```

3. Abra o arquivo `src/index.html` em qualquer navegador moderno.
